# 🚀 React Technology Showcase

## 📌 Descripción del proyecto

Este proyecto es una aplicación educativa creada con **React + Vite**, cuyo objetivo es servir como un espacio de demostración para diferentes tecnologías del ecosistema de React.

No es una aplicación funcional real (como una tienda o red social), sino un **laboratorio de aprendizaje** donde se implementan ejemplos simples tipo “Hola Mundo” para entender cómo funciona cada herramienta.

---

## 🎯 Objetivo

- Investigar la documentación oficial de cada tecnología.
- Comprender su propósito y uso.
- Implementar ejemplos básicos y funcionales.
- Integrar todo en una sola aplicación organizada por secciones.

---

## 🧱 Estructura del proyecto

La aplicación está organizada en una interfaz con:

- 🏠 Página de inicio
- 📂 Menú lateral (sidebar) con categorías:

  - UI Frameworks
  - State Management
  - Routing
  - Forms & Validation
  - Hooks
  - Testing

Cada sección contiene ejemplos prácticos de las tecnologías correspondientes.

---

## 🧪 Contenido por secciones

### 🎨 UI Frameworks
Comparación de frameworks de UI:

- Chakra UI
- Material UI
- Tailwind CSS

📌 Ejemplo: tarjetas, botones o layouts simples.

---

### 🧠 State Management
Manejo de estado global:

- Context API
- Zustand
- MobX

📌 Ejemplo: contador simple compartido.

---

### 🧭 Routing
Navegación entre páginas:

- React Router
- TanStack Router

📌 Ejemplo: páginas Inicio / Acerca de.

---

### 📝 Forms & Validation
Manejo y validación de formularios:

- React Hook Form
- Formik
- Zod

📌 Ejemplo: formulario de login con validación básica.

---

### 🪝 Hooks de React
Demostración de hooks principales:

- useState
- useEffect
- useMemo
- useCallback
- entre otros

📌 Ejemplo: casos de uso simples por hook.

---

### 🧪 Testing
Pruebas básicas de componentes:

- Cypress
- React Testing Library
- Jest
- Playwright

📌 Ejemplo: test de un contador o botón.

---

## 🔀 Metodología de trabajo

- El proyecto se trabaja en un solo repositorio.
- Cada funcionalidad se desarrolla en su propia rama.
- Todo se integra en una rama principal (`main`).

---

## 📚 Importante

- Toda la información debe basarse en la **documentación oficial** de cada tecnología.
- Los ejemplos deben ser simples y funcionales.
- El objetivo es comprender, no construir una aplicación compleja.

---

## 🧠 Conclusión

Este proyecto funciona como un **laboratorio de aprendizaje de React**, donde cada tecnología se estudia e implementa de forma aislada dentro de una misma aplicación organizada.
